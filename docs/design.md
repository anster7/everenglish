Ever English 디자인 가이드 (Design Guide)
1. 디자인 컨셉 정의
Brand Keyword
•	Trust / Calm / Premium / Growth
디자인 톤
•	과하지 않은 세련됨
•	학원 느낌 ❌ / 프리미엄 스터디 & 교육 브랜드 ⭕
•	부모가 안심하고 오래 볼 수 있는 화면
"아이를 맡기는 공간은 시각적으로도 조용해야 합니다."
________________________________________
2. 컬러 가이드 (Color System)
Primary Color
•	Deep Navy (#1F2A44)
→ 신뢰, 지성, 안정감
Secondary Color
•	Warm Ivory (#F7F5F0)
→ 종이책, 원서, 아날로그 감성
Accent Color
•	Soft Sage (#8FAF9A)
→ 성장, 안정, 학습의 지속성
Sub Accent (CTA용)
•	Muted Gold (#C7A75B)
→ 과하지 않은 프리미엄 포인트
⚠️ 원색, 고채도 컬러 사용 지양
________________________________________
3. 타이포그래피 (Typography)
국문
•	Headline: Pretendard SemiBold
•	Body: Pretendard Regular
영문
•	Headline: Playfair Display (원서·책 감성)
•	Body: Inter / Noto Sans
사용 원칙
•	자간 넉넉하게 (-2% ~ 0%)
•	행간 1.6 ~ 1.8 (가독성 최우선)
________________________________________
4. 레이아웃 시스템
기본 구조
•	Single Column 중심
•	섹션 간 충분한 여백 (White Space)
섹션 흐름
•	설명 → 공감 문장 → 시각적 구분 → CTA
카드 UI
•	Radius: 16~24px
•	Shadow: 매우 약하게 (떠 보이지 않게)
________________________________________
5. 이미지 & 비주얼 가이드
이미지 방향
•	실제 수업 분위기 또는 연출된 스터디 장면
•	과한 스톡 이미지 ❌
•	아이 얼굴 클로즈업 최소화
추천 비주얼
•	책 읽는 손, 노트, 펜, 책장
•	자연광, 따뜻한 톤
아이콘 스타일
•	Line icon + Rounded
•	두께 일정하게 유지
________________________________________
6. 인터랙티브 요소 가이드 (추천)
6-1. 스크롤 인터랙션
•	섹션 진입 시 Fade-in + Slight Up
•	속도 느리게 (0.6~0.8s)
효과: 차분하지만 고급스러운 인상
________________________________________
6-2. 지도 방식 STEP 인터랙션
•	STEP 1 → 2 → 3 순차 강조
•	Hover 또는 Scroll 시 단계 강조
효과: 수업 구조 이해도 상승
________________________________________
6-3. FAQ 인터랙션
•	Accordion 방식
•	클릭 시 부드러운 열림
효과: 정보 과부하 방지
________________________________________
6-4. CTA 마이크로 인터랙션
•	Hover 시 미세한 컬러 변화 + Shadow
•	클릭 시 Ripple ❌ (교육 브랜드와 미스매치)
추천 문구 예시
•	"우리 아이에게 맞는지 상담해보기"
________________________________________
7. 모바일 UX 가이드
•	한 화면 = 한 메시지 원칙
•	CTA 하단 고정 버튼 (Sticky)
CTA 문구
•	"1:1 상담 신청"
________________________________________
8. 하지 말아야 할 디자인 요소
•	❌ 과한 애니메이션
•	❌ 형광색, 빨간 강조
•	❌ 학원식 배너 문구
•	❌ 정보 과다 배치
________________________________________
9. 디자인 완성도 체크리스트
•	첫 화면에서 신뢰감이 느껴지는가?
•	부모가 오래 보고 싶어지는가?
•	CTA가 자연스럽게 보이는가?
•	학원이 아닌 ‘교육 브랜드’처럼 보이는가?
________________________________________
10. 확장 디자인 제안 (선택)
•	학부모 후기 섹션 (카드 슬라이드)
•	추천 원서 캐러셀
•	상담 전 간단 자가 체크 (3문항)
※ 초기에는 비활성화 가능
